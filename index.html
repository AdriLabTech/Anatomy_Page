Acerca de

Esta aplicación está diseñada para ayudar en el estudio de anatomía humana mediante preguntas interactivas sobre imágenes médicas.

Características:

  • Imágenes anatómicas con partes señaladas
  • Sistema de preguntas aleatorias
  • Feedback inmediato
  • Seguimiento de progreso
  • Posibilidad de repaso

Atajos de teclado

  • Enter verificar y, después, continuar
  • Alt + ← / → pregunta anterior / siguiente
  • Alt + S saltar · Alt + Z ampliar la lámina
  • Esc cerrar ventanas
